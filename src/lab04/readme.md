## Задание A

### read_text
![Пример read_text](/images/lab04/read_text_normal.png)
Принимает путь к файлу и кодировку, читает его целиком (хотя при очень больших файлах стоит читать построчно) при отсутствии файла или неверной кодировке падает с ошибкой.
![Пример ошибки](/images/lab04/read_text_error.png)
При пустом файле пустая строка
![Пример пустого](/images/lab04/read_text_empty.png)

### write_csv
Принимает список списков, путь файла, в который записать и список с названиями колонок. При пустых строках и шапке записывает пустой файл.
![Пример check.csv](/images/lab04/write_check.png)
![Пример empty.csv](/images/lab04/write_empty.png)
